# 🎵 Spotify Clone — Music Player UI

A **responsive Spotify-inspired Web Player UI Clone** built using HTML5 and CSS3. This project recreates the modern look and feel of Spotify's web interface, featuring a sidebar, library section, playlist and artist cards, a sticky navigation bar, and a music player layout.

The project focuses on frontend development fundamentals, responsive design, and creating a clean, modern user interface.

## ✨ Features

- 🎧 Spotify-inspired dark-themed interface
- 🏠 Home and Search navigation
- 📚 Your Library section
- 🎵 Music player interface with playback controls
- 💿 Album artwork and song details
- 📀 Playlist and artist cards
- 📌 Sticky navigation bar
- 📱 Responsive layout using CSS Flexbox and media queries
- 🎨 Modern styling with Google Fonts and Font Awesome icons

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/papridas06/spotify-clone.git
```

### 2. Open the project folder

```bash
cd spotify-clone
```

### 3. Run the project

Open `index.html` in your preferred web browser.

**No additional installation or dependencies are required.**
